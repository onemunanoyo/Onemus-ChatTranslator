# ChatTranslator

A client-side Minecraft mod that translates chat and item tooltips using the DeepL API.

[English](README.md) · [日本語](docs/readme/README_ja.md) · [简体中文](docs/readme/README_zh-hans.md) · [한국어](docs/readme/README_ko.md) · [Deutsch](docs/readme/README_de.md) · [Español](docs/readme/README_es.md) · [Français](docs/readme/README_fr.md) · [Português (Brasil)](docs/readme/README_pt-br.md) · [Tiếng Việt](docs/readme/README_vi.md) · [ไทย](docs/readme/README_th.md)

## Development

Check out the relevant version branch and follow its Gradle configuration and README. Open pull requests against that branch.

A DeepL API key is required. This unofficial mod is not affiliated with DeepL SE, Mojang, or Microsoft.
