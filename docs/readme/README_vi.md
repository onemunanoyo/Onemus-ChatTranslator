# ChatTranslator — Minecraft 1.21.11 (Fabric)

Mod phía máy khách dùng DeepL để dịch trò chuyện và chú thích vật phẩm trong Minecraft.

Nhánh này dành cho Minecraft 1.21.11 với Fabric.

## Tính năng

Dịch tin nhắn phù hợp tự động hoặc khi nhấp, dịch chú thích vật phẩm và cấu hình các kênh Hypixel. Danh sách bỏ qua so khớp chính xác và không phân biệt chữ hoa, chữ thường.

## Bắt đầu

Cài mod với đúng phiên bản Minecraft và trình tải. Bạn cần khóa API DeepL và kết nối mạng.

Nhấn J (mặc định) để mở cài đặt, nhập khóa API và chọn ngôn ngữ đích.

## Lệnh

- `/tr <text>`: Dịch văn bản và chỉ hiển thị kết quả cho bạn.
- `/trt <text>`: Dịch văn bản và đưa kết quả vào ô nhập trò chuyện.
- `/translate on` / `/translate off`: Bật hoặc tắt dịch tự động.
- `/translate status`: Hiển thị cài đặt dịch hiện tại.
- `/translate key <API_KEY>`: Đặt khóa API DeepL.
- `/translate rule add <source> <target>`: Thêm quy tắc ngôn ngữ nguồn và đích.
- `/translate rule list`: Liệt kê các quy tắc đã cấu hình.
