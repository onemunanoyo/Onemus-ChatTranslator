# ChatTranslator

Mod phía máy khách cho Minecraft, dịch trò chuyện và chú thích vật phẩm bằng API DeepL.

## Nhánh mã nguồn

`main` là trang hướng dẫn. Hãy chọn nhánh phù hợp với phiên bản Minecraft bạn sử dụng.

Chọn bản tải xuống phù hợp với phiên bản Minecraft và trình tải tại [Modrinth](https://modrinth.com/mod/onemus-chattranslator/versions).

## Phát triển

Checkout nhánh của phiên bản tương ứng và xem cấu hình Gradle cùng README của nhánh đó. Hãy gửi PR vào đúng nhánh.

Cần có khóa API DeepL. Đây là mod không chính thức và không liên kết với DeepL SE, Mojang hoặc Microsoft.
