# ChatTranslator — Minecraft 26.3 (Fabric)

Mod de cliente para traduzir o chat e as dicas de itens do Minecraft com o DeepL.

Esta branch é para Minecraft 26.3 com Fabric.

## Recursos

Traduza mensagens elegíveis automaticamente ou ao clicar, traduza dicas de itens e configure os canais do Hypixel. A lista de exclusão usa correspondência exata sem diferenciar maiúsculas de minúsculas.

## Primeiros passos

Instale o mod com a versão do Minecraft e o carregador correspondentes. São necessários uma chave da API do DeepL e acesso à internet.

Pressione J (padrão) para abrir as configurações, inserir a chave da API e definir os idiomas de destino.

## Comandos

- `/tr <text>`: Traduz o texto e mostra o resultado somente para você.
- `/trt <text>`: Traduz o texto e coloca o resultado no campo de chat.
- `/translate on` / `/translate off`: Ativa ou desativa a tradução automática.
- `/translate status`: Mostra as configurações atuais de tradução.
- `/translate key <API_KEY>`: Define a chave da API do DeepL.
- `/translate rule add <source> <target>`: Adiciona uma regra de idioma de origem e destino.
- `/translate rule list`: Lista as regras configuradas.
