# ChatTranslator

Um mod de cliente para Minecraft que traduz o chat e as dicas de itens usando a API do DeepL.

## Desenvolvimento

Faça checkout da branch da versão desejada e consulte sua configuração do Gradle e seu README. Envie PRs para essa branch.

É necessária uma chave da API do DeepL. Este mod não oficial não é associado à DeepL SE, à Mojang ou à Microsoft.
