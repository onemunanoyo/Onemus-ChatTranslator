# Contributing

- Base code changes on the Minecraft version and loader branch listed in the [README](README.md). Use `main` for repository-wide documentation.
- Keep each pull request focused. Explain the problem, what changed, and how you tested it. Link any related issues or pull requests.
- For changes that need design discussion, open an issue first and describe the problem and proposed behavior. Small fixes can go directly to a pull request.
- Use the target branch's Gradle wrapper. For a bug fix, check that your reproduction passes and that nearby behavior still works.

For chat parsing changes, include anonymized examples that should match and examples that should be skipped. Label captures and synthetic cases clearly. Remove player names, private messages, click and hover data, and API keys before sharing logs.
